# Питомец Финни — финальная версия разработки

**Версия приложения: 1.0.0 (`versionCode 2`).** Принимаем текущую
реализацию как окончательную для подготовки к сдаче 29 сентября 2026 года.
Функциональные и визуальные доработки кода завершены.

«Питомец Финни» — автономное Android-приложение для детей 7–11 лет от команды
Better Together. Ребёнок создаёт питомца, планирует монеты, совершает покупки,
копит на цель и проходит восемь занятий. Демо-режим позволяет показать пять
виртуальных дней без ожидания календарной даты и без изменения обычного профиля.
Приложение использует React Native, Expo SDK 57, TypeScript и локальный SQLite;
сервера и учётной записи нет. Android package: `com.meshnavigator.finni`.
Ориентация: portrait; минимальная версия Android: API 26 (Android 8.0).

## Локальный запуск на Android

Установите Node.js 22.18.0, npm 10.9.3, JDK 17.0.18 и Android SDK.
Состав SDK указан в `environment.md` из архива документов выше. Запустите
Android-эмулятор (API 26 или новее) в Android Studio либо подключите устройство
с включённой отладкой по USB. Из корня репозитория в PowerShell выполните:

```powershell
$env:JAVA_HOME = '<путь к JDK 17>'
$env:ANDROID_SDK_ROOT = '<путь к Android SDK>'
npm ci
npm run android
```

`npm run android` собирает и устанавливает debug-приложение, затем запускает
Metro. При последующих запусках уже установленного приложения достаточно
`npm run start` и открытия приложения на устройстве. Для локальной debug-сборки
release keystore не требуется. Если сборка на Windows завершается ошибкой из-за
пути с кириллицей или пробелами, используйте путь с латинскими символами без
пробелов; ограничение описано в `environment.md`.

## Проверка исходников

Требуются Node.js 22.18.0 и npm 10.9.3. Из корня приложения:

```powershell
npm ci
npm run verify
```

`verify` выполняет lint, typecheck, тесты, проверку учебного контента и
пятидневной fixture. Финальная версия и результат её проверки зафиксированы
в паспорте. Для проверки на устройстве используйте именно APK с указанной там
SHA-256, без Metro.

## Сборка Android APK

Нужны JDK 17.0.18, Android SDK из описания среды в архиве документов и
внешний release keystore. Ключ, пароли и файлы `.env` не входят в репозиторий.
После настройки переменных в текущем PowerShell выполните:

```powershell
$env:JAVA_HOME = '<путь к JDK 17>'
$env:ANDROID_SDK_ROOT = '<путь к Android SDK>'
$env:FINNI_RELEASE_STORE_FILE = '<путь к release keystore вне репозитория>'
$env:FINNI_RELEASE_STORE_PASSWORD = '...'
$env:FINNI_RELEASE_KEY_ALIAS = '...'
$env:FINNI_RELEASE_KEY_PASSWORD = '...'
npm run android:release
```

Скрипт не выводит пароли, не использует debug fallback и перед Gradle запускает
`lint`, `typecheck`, `test`, `content` и `fixtures`. APK появляется по пути
`android/app/build/outputs/apk/release/app-release.apk`.

Сохранённый каталог `android` не регенерируется при обычной сборке;
Windows-ограничение путей с кириллицей описано в `environment.md` из архива.

## Демонстрация и статус приёмки

Пятидневный маршрут Приложения А в архиве документов задаёт действия,
эталонные суммы и A.1–A.12. Владелец подтвердил полный проход этого сценария
на HONOR 10 Lite с Android 9 и финальным APK 1.0.0; запись результата также
входит в архив.
Сводка методического просмотра восьми занятий детским психологом также входит
в архив; он проверял сборку Sprint 3, отдельной оценки финального APK 1.0.0 нет.
Взрослый открывает Demo через «Ещё» → «Для
взрослого» после барьера. После закрытия дня «Следующий демо-день» доступен
из Домика; «Сбросить демонстрацию» создаёт новый demo-профиль, сохраняя
normal-данные. Перед прогоном запишите APK hash, commit и устройство.

Денежные правила, календарь и профиль находятся в `src/domain/`; SQLite и
атомарные команды — в `src/persistence/`; lifecycle, demo и обучение — в
`src/application/`; экраны и 2D-представление — в `src/ui/`. Контент находится
в `content/bundles/1.2.0/`, fixture — в `fixtures/`. Учебные суммы не вызывают
операции магазина или копилки.
