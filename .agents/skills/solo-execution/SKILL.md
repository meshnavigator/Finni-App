# Solo Execution

SOLO — режим выполнения без других агентских потоков. Он не выбирает модель и
не меняет reasoning: используются модель и reasoning уже открытой задачи Codex.

Если пользователю нужна конкретная модель, SOLO не подходит; используй
`$direct-model-routing` по явной команде DIRECT.

## Правила

- Не создавай субагентов, side threads или параллельные агентские потоки.
- Не передавай другим моделям исследование, реализацию, тестирование или review.
- Самостоятельно выполни анализ, изменения, проверки и итоговый review.
- Обычные инструменты — terminal, test, lint, browser, web и MCP — разрешены и
  не считаются делегированием, пока они не создают другой агентский поток.
- Если задача велика, выполняй этапы последовательно в текущем потоке.

В итоговом ответе кратко укажи:

```text
EXECUTION_MODE: SOLO
MODEL: <current model if known>
REASONING: <current reasoning if known>
SUBAGENTS_USED: NO
```
