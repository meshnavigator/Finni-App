## Что входит

Профиль и внешний вид питомца, план и итоги, магазин, копилка и цель, история,
восемь учебных занятий, взрослый раздел, отдельный пятидневный демо-режим.
Следующий демо-день запускается из Домика после закрытия текущего дня.
Финансовые операции и учебные награды сохраняются локально в SQLite.

## Как проверить

1. Сверить SHA-256 полученного APK со значением в таблице выше.
2. Установить release APK на Android API 26+ и запустить без Metro и сети.
3. Для показа открыть «Ещё» → «Для взрослого», пройти барьер и включить Demo.
   При повторном показе сбросить только демонстрацию.
4. Пройти [маршрут Приложения А](M1_DEMO_ROUTE.md); после закрытия каждого
   дня 1–4 нажать в Домике «Следующий демо-день».
5. Результаты записать вместе с моделью устройства, API, датой, SHA-256 и
   отклонениями. Ожидаемые суммы и критерии находятся в маршруте.

## Фактический Verify

`npm run android:release` выполнен 2026-09-29 из этого workspace с
Node.js 22.18.0, npm 10.9.3, JDK 17.0.18 и Android SDK 36.
Штатный скрипт сначала выполнил `npm run verify`: lint, typecheck,
166/166 тестов, content и fixtures — PASS. Gradle clean
`:app:assembleRelease` завершился `BUILD SUCCESSFUL` (302 задачи).
Скопированный APK имеет тот же SHA-256, что и выходной файл Gradle.

`aapt dump badging` подтвердил `com.meshnavigator.finni`, `versionName=1.0.0`,
`versionCode=2`, minSdk 26, targetSdk 36, ABI `arm64-v8a`, `armeabi-v7a`,
`x86`, `x86_64`. `apksigner verify --verbose --print-certs` подтвердил v2
подпись и сертификат Better Together. SHA-256 сертификата:
`902D920BBC11EF0D704766EDFE9E983D2CF96581417B30376EBE974E15495B7D`.

Установку поверх существующего `finni_s3_007_api26` остановил Android:
`INSTALL_FAILED_UPDATE_INCOMPATIBLE` — установленная там тестовая сборка
подписана другим ключом. Данные существующего эмулятора не удалялись.
На отдельном чистом `finni_final_1_0_0_api26` установка завершилась
`Success`; Android подтвердил установленную версию `1.0.0`/`2`.
Приложение запущено с `MainActivity` на переднем плане. После отключения
Wi-Fi и мобильных данных, остановки процесса и повторного запуска стартовый
экран снова отобразился без Metro. Снимок:
[`finni-1.0.0-api26-offline.png`](../artifacts/release/finni-1.0.0-api26-offline.png).
Это smoke запуска, а не полный проход финансового цикла и TalkBack.

## Открытые проверки и передача

Решение владельца закрывает этап разработки. По состоянию документации
физический Android, spoken TalkBack, performance/thermal, три полных

и независимая проверка доступа к загруженному файлу не подтверждены.
Их источники и критерии: [M1_TRACEABILITY.md](M1_TRACEABILITY.md),
[S4-001–006](../tasks/TASKS.md), [S10-001–002](../tasks/TASKS.md).

размещения следует сохранить URL, дату и контрольную сумму переданного APK,
а затем проверить скачивание и установку именно этого файла.
