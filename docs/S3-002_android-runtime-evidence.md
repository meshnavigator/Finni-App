## Границы evidence

Это debug APK с Metro, не signed/offline release. Проверка выполнена на эмуляторе API 26, не на физическом устройстве. Отдельные device/OEM/accessibility/performance gates остаются в Sprint 10. Старый signed APK имел другую подпись: для установки debug APK тестовый пакет `com.meshnavigator.finni` на этом AVD был удалён вместе с его локальными данными; пользовательские данные вне AVD не затронуты.
