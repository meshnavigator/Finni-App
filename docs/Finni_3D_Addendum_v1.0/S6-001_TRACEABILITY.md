## Выявленные расхождения

1. ТЗ требует минимум 8 покупок, 3 цели и 6 уроков, а SRS проектирует
   `IT-01..08`, `GL-01..03` и восемь `LS-*`. В коде есть только строковые поля
   команд `itemId`, `goalId`, `lessonId`; данных каталога и валидаторов ID нет.
2. `LifecycleRepository.DEFAULT_RULE_BUNDLE` использует `catalog-v1/goals-v1`,
   но runtime открывает период с `bootstrap/bootstrap`. Ни одно значение не
   доказывает наличие каталога.
3. Главный экран уже показывает 2D baseline и placeholder-данные цели, ухода и
   занятия. Это не завершённая реализация требований ТЗ §2.5.3 и HUD-005.
4. SRS фиксирует 2D-домик, а аддендум требует настоящую 3D-сцену. Владелец
   проекта принял M1 как release target и связанный schedule/high-risk
   rebaseline. Уже зафиксированные M1-артефакты нельзя перезаписывать: новые
   поставки должны иметь отдельные версии, manifests и evidence.

## Принятое решение и оставшиеся gates

DEC-2026-09-18-002 имеет статус Accepted: M1 должна содержать настоящую 3D-сцену
Home с полнофигурным Финни. Экономика, catalog IDs и существующие артефакты не
меняются. Exact renderer, native boundary, GLB pipeline и числовые бюджеты не
считаются выбранными до S7-001/S7-002 и аппаратных измерений.

S6-002 разблокирована и начата. Sprint 7 остаётся заблокирован до завершения
S6-002 и физического Android API 26 baseline. S6-001 остаётся PARTIAL, пока нет
реализованных каталогов и назначенных art, engineering и QA/device owners.

## Актуализация привязок 2026-09-23 (S8-002)

Таблица выше сохраняет исторический срез S6-001 на 2026-09-18. После
DEC-2026-09-19-006/007 активный путь — layered 2D. Фактический
`Finni App/src/domain/catalog.ts` содержит `IT-01…IT-08` и
`GL-01…GL-03`. Для каждого из этих одиннадцати ID назначен отдельный
`CAT-IT-*` либо `CAT-GL-*` PNG с локальным путём и SHA-256 в
`asset-manifest.json → reconciliation.bindings.*.individualBindings`.
Исходный пакет: `Finni App/assets/2d/room/S8-002/asset-manifest.json`.

Привязка ID закрыта технически: неизвестный ID не получает ресурс, а
существующие цены, названия, слоты и команды не менялись. Новые изображения
пока имеют статус engineering candidate до независимой художественной
приёмки и визуальной проверки на Android. Исторические 3D строки поставок
ниже в manifest не означают production acceptance для 2D. S6-001 остаётся
PARTIAL из-за ранее открытого owner/device gate; данные этого обновления не
переписывают её решение от 2026-09-18.
