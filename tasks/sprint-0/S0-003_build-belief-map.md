# S0-003: Построить belief map и зафиксировать границы модулей

## Цель
После появления кода построить карту реальных модулей для blast-radius анализа.

## Контекст
Сейчас `Finni App` пуст, поэтому belief map неприменим: задача не должна строить карту из проектных предположений.

## Состав работ
- дождаться manifest-файлов и исходных модулей;
- определить tool root по порядку из `AGENTS.md`;
- выполнить full build с исключением worktrees/generated/cache/vendor;
- через `search`, затем `analyze` проверить domain, persistence, content и UI;
- записать подтверждённые module IDs.

## Источники
- `AGENTS.md`, раздел «Belief map»;
- `.project-kit/config.json`, секция `belief_map`;
- SRS v1.3, §§14.2–14.3.

## Критерии приёмки
- карта построена из фактического `code_root`;
- копии и generated-каталоги исключены;
- границы подтверждены `analyze`, а не угаданы;
- после структурных изменений выполнен повторный full build.

## Зависимости
- S0-005.

## Verify
- full build карты;
- `search` + `analyze` для четырёх ключевых областей;
- проверка отсутствия worktrees/generated путей.

## Out of scope
- проектирование архитектуры вместо анализа;
- ручное редактирование артефактов карты.
