# S5-005: Добавить optional Family-карточки при наличии запаса

## Цель
Условно реализовать три необязательные семейные карточки только после закрытия обязательного ядра и release blockers.

## Контекст
OFF-01–03 — выбранное дополнение, не конкурсный дефект. Задача отменяется без ущерба обязательному M1/M2 при нехватке времени или отсутствии разрешения.

## Состав работ
- подтвердить явное включение Family в scope;
- добавить настройку default off за взрослым барьером;
- реализовать OFF-01–03 как вымышленные обсуждения;
- хранить только самоотчёт без денег, reward, роста и семейных данных;
- обновить manifest, tests и честное release-scope.

## Источники
- SRS v1.3, §§13.10, 24.5;
- FR-50–53; DEV-38; TC-119–125.

## Критерии приёмки
- функция выключена по умолчанию;
- карточки не требуют реальных покупок или раскрытия бюджета семьи;
- завершение не меняет деньги, награды и рост;
- отсутствие функции не помечается дефектом обязательного scope.

## Зависимости
- S5-002; закрытые обязательные блокеры; явное решение владельца.

## Verify
- component tests setting/barrier/cards;
- integration assertions zero money/reward/growth effect;
- content/privacy review.

## Out of scope
- реальные задания семье, геолокация и торговые интеграции;
- обязательность Family для релиза.
