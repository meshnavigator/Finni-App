# S5-002: Исправить приоритетные пробелы M1

## Цель
Закрыть только подтверждённые блокеры и обязательные пробелы, сохранив данные, контракты и совместимость M1-профиля.

## Контекст
Финальное окно не является резервом для десятков функций. Порядок: рекомендации и блокеры → обязательные пробелы → регрессия.

## Состав работ
- реализовать согласованные исправления минимальным diff;
- добавить миграции без потери профиля;
- обновить связанные schema/content/types/tests/docs;
- повторить доменные, SQLite и UI проверки затронутых границ;
- зафиксировать оставшиеся ограничения.

## Источники
- S5-001;
- SRS v1.3, §§15.5/15.8–15.11, 18, 21.5;
- DEV-28/30 и релевантные FR/TC из утверждённого scope.

## Критерии приёмки
- каждый diff относится к утверждённому M2 item;
- обновление тем же ключом сохраняет M1-профиль;
- старые критические тесты не регрессируют;
- скрытых новых механик нет.

## Зависимости
- S5-001.

## Verify
- targeted tests + полный configured Verify;
- migration/install-over-M1 run;
- physical smoke затронутых сценариев;
- `git diff --check`.

## Out of scope
- произвольный refactor;
- функции без рекомендации или обязательного gap.
