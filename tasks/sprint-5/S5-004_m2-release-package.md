# S5-004: Выпустить M2 APK и неизменяемый финальный комплект

## Цель
Передать подписанный устанавливаемый APK, исходники, документы и резервное видео как согласованный M2 release.

## Контекст
M2 создаётся новыми commit/tag и не перезаписывает M1. Точное время финальной загрузки должно быть подтверждено организатором.

## Состав работ
- собрать clean signed release с увеличенным versionCode;
- создать M2 tag, manifest и SHA-256;
- записать резервное видео до 3 минут;
- загрузить APK, код, документацию и материалы карточки;
- проверить ссылки/установку вне сессии владельца и заморозить комплект.

## Источники
- официальное ТЗ, §§3.3, 4.1, 7.2;
- SRS v1.3, §§21.5–21.6, 22.3/22.6/22.9;
- S5-003.

## Критерии приёмки
- APK устанавливается без dev-среды и работает офлайн;
- tag/hash/manifest/version совпадают;
- M1 остаётся доступным и неизменным;
- экспертные ссылки доступны без запроса прав.

## Зависимости
- S5-003; подтверждённый финальный cutoff.

## Verify
- clean build + install + mandatory demo;
- hash/tag/version/link checks;
- просмотр резервного видео и документов;
- `git diff --check` до tag.

## Out of scope
- RuStore-публикация;
- изменения после разрешённого окна.
