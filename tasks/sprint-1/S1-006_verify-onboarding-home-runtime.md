# S1-006: Проверить onboarding и домик на Android 360 dp

## Цель
Закрыть отложенный runtime-gate S1-004 на неизменяемом подписанном APK: пройти
первый запуск, два вида питомца и восстановление профиля после остановки
процесса на Android-устройстве шириной 360 dp.

## Evidence
- реализация S1-004, component/integration tests и clean release build готовы;
- исходный APK `finni-0.1.0-s1-004-release.apk`, SHA-256
  `066830FD54824AE9C6DC0D73167E6D4819B91FFEA8FBA165DE3E59798ABD9930`,
  получил runtime FAIL из-за перекрытия Android status bar;
- финальный APK `finni-0.1.0-s1-004-r4-release.apk`, SHA-256
  `3486DA3B6F0BFC46FC03D52CE2E2C825DF818CEE62A222D24732BF0EDD6B2804`;
- AVD `small_phone`: Android API 36, 720×1280 px, density 320 = 360×640 dp;
- полный протокол: `Finni App/artifacts/sprint-1/runtime/S1-006_RUNTIME_EVIDENCE.md`.

## Состав работ
- подключить Android-устройство или неизменяемый AVD с полезной шириной 360 dp;
- проверить onboarding без сети/регистрации и создать профиль с первой
  комбинацией питомца;
- открыть домик на 360×640 dp при fontScale=1 и зафиксировать отсутствие
  обрезания обязательных сводных данных и целей касания меньше 48 dp;
- из домика изменить имя и внешность на вторую комбинацию, отменить отдельное
  несохранённое изменение и убедиться, что ID/деньги не пересоздались;
- принудительно остановить приложение, запустить APK без Metro и подтвердить
  восстановление имени, вида питомца и финансового состояния;
- при доступности проверить fontScale=2 как scroll-fallback без потери данных.

## Критерии приёмки
- каждый evidence-прогон использует неизменяемый APK с зафиксированным hash;
- final PASS относится только к r4 SHA-256 из Evidence;
- TC-001/003/075/183/185 имеют фактические наблюдения, устройство/версию ОС и
  снимки экрана либо видеозапись;
- на 360×640/fontScale1 одновременно доступны имя, день, баланс, копилка,
  цель, питомец, состояние, активное занятие, основное действие и навигация;
- после повторного запуска восстановлена вторая из проверенных комбинаций;
- профиль остаётся единственным, а редактирование не меняет деньги и историю.

## Зависимости
- S1-004 implementation и зафиксированные исходный/final APK/SHA.

## Verify
- `adb install -r <fixed-apk>` и сверка package/version;
- фактический прогон 360×640/fontScale1;
- повторный запуск после `adb shell am force-stop com.meshnavigator.finni`;
- две разные комбинации из 9 и отмена несохранённого edit;
- запись модели устройства, API, разрешения/плотности, SHA-256 и наблюдений.

## Out of scope
- изменение кода или пересборка APK внутри отдельного immutable evidence-прогона;
- финальная иллюстративная полировка;
- несколько питомцев и сюжетная кампания.
