# S4-006: Зафиксировать и передать неизменяемый M1

## Цель
Создать проверяемый M1-комплект, загрузить его до внутреннего cutoff и сохранить доступ без подмены после дедлайна.

## Контекст
Внутренняя цель — 29 сентября 20:00 МСК, официальный дедлайн — 23:59 МСК. После него решение не дорабатывается до отдельного разрешения финалисту.

## Состав работ
- выполнить release gate и зафиксировать честный M1-scope;
- создать release tag, manifest и SHA-256 артефактов;
- подготовить APK либо документированный fallback ТЗ §7.1;
- загрузить код, документы, скриншоты и короткое резервное видео;
- проверить экспертный доступ из независимой сессии и заморозить URL.

## Источники
- официальное ТЗ, §§4.1, 7.1;
- SRS v1.3, §§21.3–21.6, 22.5, 22.9;
- DEV-18/42/47; NFR-17/21/22; TC-084, TC-144/145/150/152, TC-188/189.

## Критерии приёмки
- manifest, hashes, tag и фактические файлы согласованы;
- ссылки доступны без личной сессии владельца;
- fallback не скрывает отсутствующие обязательные функции;
- M1 не изменяется после официального дедлайна.

## Зависимости
- S4-005.

## Verify
- полный configured Verify и clean release build;
- проверка SHA-256/tag/manifest/links;
- независимая установка или запуск fallback;
- `git diff --check` перед фиксацией.

## Out of scope
- изменения после дедлайна;
- M2, презентация и RuStore-публикация.
