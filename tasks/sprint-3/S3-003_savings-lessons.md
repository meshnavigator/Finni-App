# S3-003: Добавить задания S01/S02 по накоплениям

## Цель
Реализовать два задания о плане достижения цели и последствиях снятия накоплений.

## Контекст
Учебный расчёт срока и снятия не является реальным переводом из копилки и не должен менять основной баланс.

## Состав работ
- реализовать LS-S01 «Мечта за три шага»;
- реализовать LS-S02 с preview изменения цели при снятии;
- дать L1/L2 опоры и разбор обоих исходов;
- связать наблюдаемые действия с EDU-05/06;
- проверить целые суммы и понятные формулировки 7–11 лет.

## Источники
- образовательная рамка, табл. 1, стр. 4, «Личные сбережения»;
- SRS v1.3, §§13.6–13.7;
- FR-20–23; DEV-20; TC-041/042 и контентные TC.

## Критерии приёмки
- ребёнок составляет выполнимый план накопления;
- preview показывает новое накопление/остаток без проводки;
- объяснение не обещает доходность и реальный срок;
- обе задачи доступны в demo сразу.

## Зависимости
- S3-001.

## Verify
- evaluator tests сумм/срока/снятия;
- component tests обоих сценариев;
- проверка отсутствия денежных проводок.

## Out of scope
- проценты, вклады и финансовые продукты;
- изменение основной цели из учебного задания.
