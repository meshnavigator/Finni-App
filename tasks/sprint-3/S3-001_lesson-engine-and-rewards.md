# S3-001: Реализовать движок заданий и награды

## Цель
Создать расширяемый LessonShell с действиями, последствиями, объяснением и одной наградой за период.

## Контекст
Задание не может быть только тестом с вариантами; учебные суммы изолированы от кошелька, а единственный денежный эффект — `LESSON_REWARD`.

## Состав работ
- реализовать renderer registry и контракты attempt/evaluation/outcome;
- поддержать действие → последствие → объяснение → следующий шаг;
- реализовать L1/L2 подсказки без автоподтверждения ответа;
- завершать допустимый неудачный исход с разбором;
- начислять 20 ровно один раз за период транзакционно.

## Источники
- официальное ТЗ, §§2.5.8–2.5.9;
- SRS v1.3, §§4.4/4.6, 5.3, 7.6–7.7, 13.1/13.11–13.12;
- FR-07/20–23/42/43; DEV-12/33/39; TC-037–046, TC-108–115.

## Критерии приёмки
- renderer добавляется без изменения основной навигации;
- учебные действия не создают покупок/переводов;
- правильный и допустимый неудачный исход получают объяснение;
- concurrent Complete не дублирует reward.

## Зависимости
- S1-002, S2-005.

## Verify
- unit tests evaluator и reward quota;
- component tests LessonShell/hints/outcomes;
- integration tests concurrent complete/restart/closed period.

## Out of scope
- адаптивный ИИ;
- конкретные восемь сценариев контента.
