## Визуальные изменения

| Before | After |
| --- | --- |
| Пять слитых однотипных полос сверху, отдельная плашка имени | Одна финансовая панель и компактная сводка состояния/занятия; имя остаётся в доступном pet target, имя и день — в меню крупного режима |
| Слабая иерархия и жирный плотный текст | Тёплый тёмный текст, обычные/medium веса, раздельные уровни сумм, цели, подписей; предсказуемая Android line-height без дополнительного font padding |
| Кнопки справа выглядели как маленькие подписи; «взрослого» разрывалось внутри слова | Подписанные кнопки с локальными line icons, явный перенос между словами; отдельная компактная геометрия короткого экрана |
| Маленький питомец при высоком экране | Более широкая область Финни слева от боковых действий; граница сверху вычисляется по фактической высоте текстового блока |
| Мелкие предметы разбросаны по комнате | Планер на столике и сундук у нижнего края, забота в свободном боковом месте; выбранная цель показана своим изображением в финансовом HUD |
| Текстовая нижняя навигация без выделения | Локальные иллюстрации/иконка и мягкая активная поверхность «Домика», отдельный терракотовый CTA |
| Large CTA наследовал тёмный цвет от общего largeText | Белый текст основного действия сохранён при 150–200% |
| При крупном тексте насыщенная сцена конкурировала с чтением | Только фон комнаты приглушён до opacity .14; сам Финни сохраняет контраст |
| Обязательная сводка выглядела как тяжёлый сплошной блок | Разделённые спокойные поверхности, обычные начертания подписей, полные суммы/цель/остаток/занятие |
| Единица валюты могла потеряться при пустой цели | В крупном режиме без цели видна дополнительная подпись «Монеты» |
| Нажатие только снижало opacity | Добавлен scale .96 к RouteButton, сохранена минимальная зона касания |
| Проверялись размеры clickable targets, но не их пересечения | native-matrix.py проверяет и пересечения; реально обнаруженные overlap занятие/pet и help/сундук исправлены |

FontScale не ограничен, numberOfLines и скрывающего обязательную сводку scroll нет. Все target-проверки используют реальные Android dp/XML. Изменение касается Home presentation: application/domain/SQLite правила, финансовые подтверждения, ассеты внешностей и мимики сохранены.

## Границы

- Макеты и runtime просмотрены исполнителем; новая художественная приёмка владельцу не приписана.
- 200% намеренно имеет меньшего Финни по ранее принятому решению о строгой одновременной сводке.
- Физический Android/performance и озвучивание настоящим TalkBack — NOT RUN; прежние gates не закрыты.
- QA APK x86_64 подписан общеизвестным локальным debug keystore, не production release.
- Изменение presentation не добавляет новых финансовых/renderer решений. DEC-2026-09-25-012 сохраняется; current implementation и запись задачи уточнены. Топология и workflow диаграммы S9_001_HOME_LAYERS не меняются.
