# Достижимые экраны и состояния — 2026-09-25

Источник инвентаря: AppRoot Screen/render branches, HomeScreen callbacks, пять зарегистрированных lesson renderers, native переходы. Наличие render branch не считается доказательством достижимости.

| План DRAFT / дополнение дохода | Root План | Уже тёплый стиль; проверяются форма, предупреждение, точные суммы, подтверждение и отмена дополнения |
| Покупка / перевод / получение цели / закрытие / reset-delete | Native Alert поверх соответствующего экрана | Системные подтверждения и тексты последствий сохранены |
| Loading / boot error / recovery | Инициализация / ошибка данных | Общая палитра, safe area, прокручиваемое содержание при большом тексте |

Отдельных Settings, Ledger, Family или экрана товарной детали в маршрутах нет. Preferences находятся у взрослого, операции — в History, покупка — native Alert. SectionScreen — fallback для неизвестного openSection(title); реальные Home callbacks передают только обработанные значения, поэтому отдельным достижимым экраном он не объявляется. Его palette также наследует общий стиль.

## Границы

Application/domain/persistence, SQLite schema, canonical lesson content, evaluators, command/receipt правила и принятые PNG не меняются. S9-002 presentation-event controller не реализуется этим визуальным пакетом; задача остаётся отдельной. Источники: Accepted DEC-013 и новое прямое согласие владельца, ТЗ §§2.5,3.6, SRS §§9–13, S9-003/004.

Фактические результаты Verify, lineage сборок, промежуточные дефекты и ограничения записаны в README.
