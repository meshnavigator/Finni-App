# Цветовые акценты Домика — 2026-09-28

Источник: код ветки `ui/finni-color-accents`,
согласованные пользователем природные акценты и SRS §8.1/§14.1.

## Изменения

- `home-colors.ts`: четыре небольших цветовых акцента и светлые заливки.
- Home: бирюзовый коврик, декоративное окно из native View; tint только иконок
  еды/ухода/настроения. Текст, геометрия основных блоков и цвет CTA `#AE482A`
  сохранены. Крупный текст использует прежнюю компактную сводку без декора.
- RootNavigation: цветные контурные иконки, подложка и цветная подпись только
  выбранного раздела; «Ещё» остаётся нейтральным. Размеры и маршруты сохранены.
- Снятие: presentation expression `neutral` (доменный `calm`), клип AN-012.
  Валидное новое снятие вытесняет предыдущую эмоцию/очередь; stale/duplicate
  receipts не прерывают отображение и не повторяют финансовую операцию.

## Android runtime

AVD emulator-5554, Android API 26; отдельный пакет
`com.meshnavigator.finni.qa`, существующий debug APK + свежий Metro bundle
из рабочего кода (980 modules). QA-профиль создан через интерфейс.
Основной пакет `com.meshnavigator.finni` и его данные не изменены.

- `home-updated.png/xml`: 1080×1920 px, density 420, font scale 100%.
  Видны все согласованные акценты; окно не пересекает Финни стадии 1,
  подписи состояния читаются; CTA «Начать день» прежнего цвета.
- `home-360x640-200.png/xml`: 945×1680 px, density 420, font scale 200%.
  Одновременно видны суммы, цель, состояния, занятие, меню и CTA.
- `menu-360x640-200.png/xml`: все пять подписанных цветных маршрутов,
  выбран только Домик. Отдельная плашка и жирная подпись дополняют цвет.
- `home-native.png/xml` — исходное установленное основное приложение;
  это снимок ДО подключения текущего кода, не evidence новой реализации.

Первое подключение Metro только по IPv6 не удалось. LAN-вариант был отклонён
автоматической проверкой из-за возможного раскрытия dev bundle локальной сети.
Использован безопасный `node --dns-result-order=ipv4first ... start --localhost`:
Metro слушал только 127.0.0.1. Исходные wm size и отсутствие font_scale
восстановлены после проверки, QA и временный Metro остановлены.

Новая offline/release сборка, физический телефон и стадии 2/3 этим пакетом
не проверялись. Снятие подтверждено regression-тестом реального SQLite repo
и runtime reducer, отдельный UI-проход перевода на AVD не выполнялся.
Архитектура и экономика не менялись; CURRENT_IMPLEMENTATION и схема
presentation flow дополнены. Существующие чужие изменения AppRoot,
BudgetPlanScreen и отчёты сохранены.
