## File-backed SQLite integration

`node --test tests/demo-runtime.test.mjs` — PASS: два теста. Новый тест трижды выполняет 5 дней через `AppRuntime` и реальный file-backed SQLite. В каждом прогоне: 8 стандартных занятий с успешным ответом, оценкой, прочитанным объяснением и завершением; 15 покупок и отклонённая IT-08 без списания; 5 начислений дохода, ровно 5 наград; 4 взноса, получение GL-01; 5 закрытий и 4 перехода VirtualClock без ожидания. Итоги дней: B/S 20/40, 10/40, 20/90, 20/140, 40/30; рост 3/4/7/10/13; стадии 1/1/2/2/3. SQL-счётчики проверяют periods, lesson_completion, purchase, goal_claim, PERIOD_INCOME и LESSON_REWARD.

- `npm run fixtures` — PASS.
- `npm run content` — PASS только после временной byte-level нормализации CRLF→LF в checkout; Git diff контента затем возвращён. В обычном Windows checkout `core.autocrlf=true` все 12 raw SHA256 manifest-файлов расходятся с CRLF-байтами; tracked Git blobs после нормализации совпадают с manifest. Поэтому единый `npm run verify` в исходном checkout — FAIL на `catalogs/assets.json`, хотя lint/typecheck/test до этого прошли.
- `git diff --check` — PASS.

Открытый gate: полный ручной A.1–A.12 на проверяемом поставочном release APK и три native прогона с записью экрана. File-backed reset проверяет удаление demo DB, но не нажатие UI-команды. Подпись поставочного APK, физическое Android-устройство и методический проверяющий проверяются отдельно.
