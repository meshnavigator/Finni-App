**owner-accepted (2026-09-25)**. Принятые `neutral`, `blink` и `source.ora` пакета

## Воспроизведение

Из `Finni App`:

```text
python -B artifacts/sprint-8/S8-001-expressions-v1/build_expressions.py
python -B artifacts/sprint-8/S8-001-expressions-v1/verify_expressions.py
python -B artifacts/sprint-8/S8-001-expressions-v1/package_expressions.py
node --test tests/finni-expressions.test.mjs
```

Генератор выделяет только глаза/брови/мордочку из трёх полноформатных
изображений; все прочие пиксели, силуэт, окрасы, уши и поза берутся из
принятой матрицы. Каждый новый кадр хранит отдельный `pet-expression`, а
остальные восемь экспортных слоёв повторяют neutral исходника. Техническая
проверка охватывает 27 сочетаний внешности и стадии и 81 рендер
(каждое сочетание с тремя выражениями).

## Image Gen

Режим: встроенный `image_gen`, use case `precise-object-edit`. Целевой кадр:
`FINNI-MATRIX-V1/pointy-plain/neutral.png`, прозрачный canvas 941×1672.
`happy-imagegen.png` и `thoughtful-imagegen.png` созданы отдельными вызовами
по принятому neutral. Новый `inspired-imagegen.png` получен из сохранённого
экспериментального `input/inspired-reference-thoughtful.png`: его взгляд
заметно поднят, а рот раскрыт шире. Предыдущий inspired, слишком похожий на
happy, сохранён в `rejected/`. Точные промпты и референсы —
`imagegen-prompts.json`. Цели промптов:

- **happy:** изменить только лицо: более открытая радостная улыбка и
  немного улыбающиеся глаза; оставить уши, шерсть, тело, лапы, хвост,
  ошейник, медальон, позу, свет, canvas и прозрачность без изменений.
- **thoughtful:** изменить только взгляд, брови и рот: взгляд слегка вверх
  в сторону, одна бровь приподнята, маленькая закрытая задумчивая улыбка;
  сохранить оба глаза открытыми, размеры персонажа и исходный силуэт.
- **inspired:** изменить только взгляд, брови и рот: широко раскрытые глаза
  со взглядом заметно вверх, приподнятые брови и широко открытый
  радостный рот; сохранить персонажа, размеры и исходный силуэт.

Для каждого вызова также заданы прозрачный фон, запрет новых объектов,
надписей и водяных знаков. Генерация дала небольшие изменения вокруг лица;
в финальных кадрах используются только локальные лицевые области с мягкой
границей. Полные Image Gen исходники сохраняются для аудита, но не
используются напрямую в runtime.

## Границы Verify

`verification.json` фиксирует точную реконструкцию кадров и ORA, хеши
принятого baseline, координату стоп `(470,1272)`, отсутствие выхода
силуэта за canvas на стадиях 1/2/3 и локализацию изменений в области лица.
Runtime Home пока показывает neutral/blink; переходы к новым выражениям,
клипы S8-003 и проверки на Android входят в следующий интеграционный gate.
Художественная приёмка новых выражений принадлежит владельцу.


## Коррекция inspired после просмотра

Пользователь заметил, что в первом и третьем рядах обзорного листа выражения почти совпадали. Отвергнутый исходник сохранён в `rejected/`; вместо него выбран вариант с отчётливым взглядом вверх и более открытым ртом. Обновлены девять inspired PNG, их слои, девять ORA и обзорные листы стадий. Проверка `verify_expressions.py` дополнена порогом различимости лиц happy/inspired для каждой внешности; фактическая средняя разница RGB в области лица составляет 30.51–30.81 при пороге >27. Повторный `npm run verify`: 133/133 теста, lint/typecheck/content/fixtures PASS.
