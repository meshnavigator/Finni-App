# Крап на задних бёдрах: две пробы Image Gen

2026-09-25. Статус: художественная концепция проверена частично; обе пробы непригодны как точная замена принятого master. S8-001 не закрыта.

После прикрепления пользователем принятого PNG непосредственно в чат встроенный Image Gen выполнил две генерации. Локальный путь ранее не читался из-за Windows sandbox helper; передача пользовательского вложения обошла этот транспортный сбой. CLI/API и редактирование изображений через Python/Pillow не использовались. PNG скопированы без обработки.

## Что выяснилось

- **v1**: рисунок ограничен видимыми задними бёдрами; передние лапы перекрывают его, поперечного пятна нет. Но коричневые завитки и неровные пучки местами похожи на испачканную шерсть. Остальные области тоже перерисованы.
- **v2**: после запроса меньшего числа отдельных веснушек крап выглядит аккуратнее. Однако генератор увеличил персонажа и заметно изменил лицо. Сохранение размера canvas не означает сохранение масштаба персонажа.
- Расположение крапа по отдельным анатомическим поверхностям работает лучше общего overlay. Естественность и различимость окончательного рисунка ещё не приняты владельцем. Эти пробы не доказывают пригодность узора в Home или для всех стадий.

## Нужны ли существующие слои

Для первой художественной пробы хватило цельного принятого PNG. Для точного переноса окраса в производство и анимации слои необходимы. Принятые уши, хвост, лицо и аксессуар следует использовать как исходную базу. Внутри pet-body дополнительно нужны границы задних бёдер, корпуса и перекрывающих передних лап; существующий общий alpha этого не задаёт. Движение требует скрытой анатомии, которую плоская картинка не восстанавливает.

Следующий художественный шаг — локальная работа с областью каждого заднего бедра в editable source и сборка с исходными защищёнными частями. Это ещё не сделано и не выдается за готовый layered asset. Повторная генерация целого персонажа не обеспечила точное сохранение принятого образа.

## Provenance

- v2: accepted master как единственная база и v1 как отрицательный пример, `num_last_images_to_include=2`, prompt-v2.txt.
- Генерации вызваны основным потоком по точному заданию единственного DIRECT-исполнителя; художественная оценка выполнена исполнителем.
