# S8-001 — пересмотр рисунка шерсти, 2026-09-25

Статус: обе предыдущие пробы pointy/spots отклонены владельцем. Это анализ и план художественной пробы, не новый принятый asset.

## Вывод

Слой pet-body объединяет корпус и все лапы. Ограничение пятен alpha этого слоя не учитывает перекрытие передних и задних конечностей. Во второй пробе три процедурных пятна лишь перенесены на плечи; сохранение исходной яркости не устранило поперечный рисунок и эффект накладки. Нулевые изменения в защищённой области доказывают границы редактирования, но не естественность шерсти.

## Рекомендуемая проба

Начать с принятого neutral, а не с отклонённого кандидата. На каждом видимом заднем бедре отдельно нарисовать редкий нерегулярный крап как цвет отдельных пучков шерсти. Границы определяются анатомией, передняя лапа перекрывает заднюю. Размер, направление волосков, свет и тень берутся из локальной формы. Грудь и светлые носочки сохраняются. Художественный масштаб проверить рядом с plain в Home; маленькая площадь бёдер может оказаться недостаточно различимой.

В editable source создать вложенные группы частей тела: rear-left, rear-right, torso, foreleg-left, foreleg-right; окрас клиппируется внутри каждой части. Это предлагаемая структура исходника, а не принятая смена runtime-контракта. На экспорте запекать узор в pet-body/pet-back, сохраняя девять внешних слоёв, canvas 941×1672 и origin (0,0). Контракт допускает пустой pet-pattern. В экспортном наборе каждой внешности будут собственные PNG корпуса; смена общего overlay не обязательна.

Слой окраса может использовать Multiply/Color как рабочий инструмент художника, но один режим наложения не решает анатомию. Для neutral-пробы достаточно видимых областей. Для движения лап необходимо дорисовать скрытую шерсть; принятый плоский PNG и его вырезы этой информации не содержат.

## Альтернативы

- Естественные крупные участки окраса: меньше мелкого шума, но всё равно нужны анатомические маски и художественная проба. Трактовку spots как крупных пятен согласовать до внедрения.
- Оставить plain как текущую принятую внешность. Это сохраняет качество, но не закрывает требование 3×3.
- Замена рисунка одним общим оттенком или аксессуаром не закрывает текущую SRS о трёх рисунках. Переименование spots/stripes и изменение публичных ID не выполнялись.
