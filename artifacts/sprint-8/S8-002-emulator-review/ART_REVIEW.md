# S8-002 — файлы для художественной приёмки

Проверьте два обзорных листа, затем оригинальные PNG в архиве.

1. Home: композиция комнаты, свет, материалы и четыре объекта по углам; лицо Финни остаётся открытым.
2. OBJ-PLANNER, OBJ-CHEST, OBJ-CARE, OBJ-GOAL-DISPLAY, OBJ-COIN: стиль и читаемость пяти предметов.
3. IT-01…IT-08 и GL-01…GL-03: узнаваемость и качество миниатюр в каталоге, согласованность с комнатой.
4. Отдельно отмечайте конкретный файл и замечание. Можно принять часть файлов и вернуть остальные на исправление.

ROOM-BASE уже был принят в S7-004; он включён для сравнения композиции.
Снимки сделаны на одном Android API 26 AVD 360×640 dp с debug APK и Metro.
Это не проверка физического устройства, release/offline режима или всей логики покупок.
Техническое отображение всех 8 IT и 3 GL на этом эмуляторе проверено.
