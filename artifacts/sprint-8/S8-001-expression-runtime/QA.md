# S8-001/S8-003: runtime-мимика и Android QA

Дата: 2026-09-25. Устройство: Android Emulator `emulator-5554`, API 26, debug APK + локальный Metro. Это проверка текущего JavaScript/asset bundle, а не signed/offline release.

## События и переходы

- `GOAL_SELECTED` → thoughtful; успешное пополнение копилки → inspired (уточнение владельца по SRS); успешная покупка и награда за урок → happy; получение цели и смена стадии → inspired. Снятие и ошибки не запускают положительную реакцию.
- В Home реакция показывается только после успешной команды и загрузки кадра. Через 2,5 с возвращается calm. Новое событие заменяет старое, устаревший callback не сбрасывает новый кадр; уход с экрана, модальная пауза, уход приложения в фон и reset отменяют реакцию.
- Для получения цели и смены стадии кнопка пропуска мгновенно ставит статичный финальный кадр и не меняет уже сохранённый результат. При выключенном движении показывается статичный кадр без перехода.
- На API 26 вручную пройдены goal selection → thoughtful, deposit → inspired, purchase → happy, goal claim → skip (сохранены кошелёк и стадия), deposit → Help modal → cancel/calm. Видео: `thoughtful.mp4`, `inspired.mp4`, `happy.mp4`, `skip-final.mp4`, `cancel.mp4`; общий ролик: `animations-check.mp4`.

## Матрица внешности и стадии

Сценарий `runtime_matrix.py` по очереди подставляет QA-копию SQLite для `pointy|round|floppy × plain|spots|stripes × stage 1|2|3`, запускает Home cold start, проверяет accessibility stage и отсутствие image fallback, ждёт фактически отрисованный кадр и делает снимок. **27/27 PASS**. Подробности: `matrix.json`, снимки `matrix/*.png`, обзор `android-9x3-room.jpg`.

Первый прогон снял два кадра до завершения загрузки. После исправления сценария все 27 повторены; дисперсия пикселей области сцены 4028–4049 (порог 3000), пустых снимков нет. Ранее принятый пакет `S8-001-expressions-v1` отдельно подтвердил 27 кадров мимики и 81 статический рендер по стадиям; данный Android sweep показывает 27 neutral Home и событийные реакции на одной из комбинаций, но не 81 событийную реакцию на Android.

## Проверки и границы

- Полный `npm run verify` PASS: lint, typecheck, 133/133 tests, content, fixtures. `git diff --check` отдельно.
- Изображения и stage/anchor contract не изменялись; использованы принятые хеши `FINNI-MATRIX-V1` и `FINNI-EXPRESSIONS-V1`.
- Физический Android сейчас недоступен по сообщению владельца. Поэтому S10 performance/OEM/low-memory и физическая приёмка остаются открытыми. Signed release без Metro и offline full-flow ×3 также не проверены: четыре переменные внешней подписи отсутствуют в текущем окружении. Текущий ролик записан с debug APK + Metro.
- QA-сценарий использовал временные SQLite fixtures на AVD. Оригинальная база AVD восстанавливается после проверки. Пользовательские данные вне AVD не затронуты.
