# S8-001 — пробный набор слоёв Финни

Статус: **образец для художественной проверки, не ресурс приложения**.
Принятый `FINNI-2D-MASTER-V1` не заменён. Исходник и точные SHA-256
указаны в `prototype-manifest.json`.

## Что можно открыть

- `source/finni_neutral_layers_prototype.ora` — OpenRaster для Krita/GIMP;
- `layers/*.png` — девять полноразмерных слоёв 941×1672 в порядке
  `FINNI-S8-001-LAYER-CONTRACT.md`;
- `review/accepted-vs-reassembled.png` — принятый нейтральный Финни слева,
  собранный из слоёв справа;
- `review/layer-breakdown.png` — отдельные части с видимыми границами вырезания;
- `review/contour-audit.png` — границы каждого вырезанного слоя поверх принятого Финни;
- `review/stage-1-2-3.png` — предварительный просмотр масштабов
  0.86/1/1.12 с якорем лап `(470, 1272)`.

Команда пересборки из каталога `Finni App`:

```text
python -B artifacts/sprint-8/S8-001-layer-prototype/build_layers.py
```

Нужен Pillow 10.4.0. Сборка проверяет хеши принятого PNG и комнаты, полный
размер холста, архив ORA и точное совпадение видимых пикселей нейтрального
Финни после сборки. Результат: **0 отличающихся видимых пикселей**.

## Граница образца

Форма `pointy` и узор `plain` в манифесте — предварительная визуальная
классификация принятого рисунка. Остальные восемь внешностей не изготовлены.
Слои `pet-pattern` и `pet-expression` пусты. Нейтральное лицо сохранено в
`pet-face`, ошейник — в `pet-accessory`, хвост — в `pet-back`.

После замечания о грубых вырезах контуры хвоста, обоих ушей, подбородка и
ошейника уточнены по исходному PNG; каждый слой можно проверить на
`review/contour-audit.png`. Это точное разнесение *видимых* пикселей,
а не перерисованный cutout rig:
под отделёнными ушами, лицом и ошейником нет скрытой шерсти. Для смены формы,
узора или выражения художник должен дорисовать закрытые участки, края и новые
состояния, затем проверить 3 стадии × 9 внешностей по контракту. Отдельный
blink из S7-004 меняет пиксели по всему силуэту, поэтому его нельзя выдать за
готовый сменный слой лица. В production до художественной приёмки этот пакет
не подключать.

Доступный S7-004 ORA содержит только три плоских слоя: `Pet neutral`,
`Pet blink` и `Room clean`. Послойного рисунка анатомии в нём нет.
Художественная пригодность уточнённых масок пока не подтверждена.
