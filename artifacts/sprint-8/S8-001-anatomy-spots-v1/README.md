# S8-001 — отдельные части тела и пятна на четырёх лапках

2026-09-25. **Статус: рисунок отклонён владельцем; точное анатомическое разделение используется дальше.**

Корпус принятого neutral разделён на шесть вложенных частей: `rear-left`,
`rear-right`, `foreleg-left`, `foreleg-right`, `chest`, `torso`. Стороны указаны
со стороны зрителя. В каждой части ORA находятся отдельные `base` и `pattern`.
Исходные лицо, уши, хвост, аксессуар и комната сохранены. Грудь оставлена светлой:
она поддерживает композиционный центр с медальоном; пользователь предложил
пятна на груди как опцию. Её отдельный слой готов для последующей работы.

В кандидате по три небольших коричневых пятна на передних и задних лапках.
Они не пересекают границы конечностей и не доходят до светлых носочков.
Крупный и уменьшенный Home-предпросмотр визуально осмотрены. В масштабе Home
это мелкие различимые веснушки; их художественный размер, плотность и характер
ещё должен оценить владелец. Рисунок не объявляется принятым.

## Как изготовлено

1. `build_anatomy.py` распределяет существующие RGBA-пиксели `pet-body` между
   непересекающимися анатомическими частями. Нейтральная сборка точно совпадает
   с master. Скрытая под перекрытиями шерсть не выдумывается.
2. Встроенный Image Gen создал отдельный прозрачный слой пятен. Он не рисовал
   нового Финни для этой итоговой сборки. Первая крупная проба отклонена;
   её исходник и сравнение сохранены с суффиксом `v1-rejected`.
3. Второй overlay содержит 12 отметин, но не выдержал требуемые координаты и
   размеры. `register_overlay.py` выделяет готовые raster-отметины, пропорционально
   уменьшает и размещает их внутри четырёх частей. Операции перечислены в
   `registration.json`; рисование пятен, подбор процедурного цвета или перекраска
   исходного Финни в Python не выполнялись. Цвет и фактура отметин принадлежат
   результату Image Gen. Техническое размещение использует crop, uniform resize,
   translation и обычную alpha-сборку.
4. Каждая отметина клиппируется по своей части. Пиксели не обрезаются защитной
   границей в итоговом кандидате. В ORA `pattern` остаётся отдельным слоем;
   в девяти внешних PNG узор запечён в `pet-body`, `pet-pattern` пуст по контракту.
   Остальные восемь экспортов скопированы побайтово из принятого прототипа.

## Воспроизведение

Требуется Python и Pillow 10.4.0 (установленная версия, новая установка не нужна).
Команды выполняются из корня проекта:

```powershell
python -B "Finni App/artifacts/sprint-8/S8-001-anatomy-spots-v1/register_overlay.py"
python -B "Finni App/artifacts/sprint-8/S8-001-anatomy-spots-v1/build_anatomy.py"
python -B "Finni App/artifacts/sprint-8/S8-001-anatomy-spots-v1/verify_anatomy.py"
```

## Ограничения и источники

Это visible-neutral extraction, а не полный анимационный rig. Для независимого
движения лап потребуются скрытая анатомия и дополнительные позы. 27 сочетаний,
мимика и художественная приёмка S8-001 остаются открытыми. Новый master не заменяет
S7-004; runtime не подключён. Источники: принятый FINNI-2D-MASTER-V1, принятый
neutral layer prototype, FINNI-S8-001-LAYER-CONTRACT.md и текущий запрос владельца.

CURRENT_IMPLEMENTATION и прогресс S8-001 дополнены. Схема экспериментального
workflow записана в `docs/mermaid/S8_001_ANATOMY_PATTERN_TRIAL.md`. Новое Accepted
архитектурное решение не создаётся: внешний runtime-контракт сохранён, рисунок
пока не принят. Belief-map для runtime не пересобиралась: runtime-модули, imports,
маршруты, SQL и публичные контракты приложения не изменены; скрипты локальны
художественному пакету и не входят в приложение.
