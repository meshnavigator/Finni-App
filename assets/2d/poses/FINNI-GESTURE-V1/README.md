# FINNI-GESTURE-V1 — принятый жест лапой

2026-09-28, DIRECT Astra Medium. По поручению владельца изготовлены три
новые lower-body позы plain/spots/stripes для AN-004 и AN-008. Все девять
внешностей используют принятую голову своей формы и мимику, а стадии —
прежние размеры/опору лап. Владелец явно принял новые позы и анимации 2026-09-28. Приёмка связана с
точными source/export SHA256 в `owner-acceptance.json`; runtime/performance
и release gates этим не закрываются.

Исходники `plain.png`, `spots.png`, `stripes.png` созданы встроенным ImageGen.
Первый target — принятый pointy/plain neutral. Запрос: поднять переднюю лапу
справа от зрителя, сохранить четыре конечности, сидячую опору, хвост, размер,
окрас, лицо и прозрачность. Затем от plain wave получены body-coat variants:
коричневые пятна и поперечные полосы с чистой грудкой, без смены геометрии.
Промежуточный вариант spots по двум reference images отбракован: лишняя лапа
и изменённый размер. Он не включён в assets или runtime.

Generated source IDs, каталог `01a0e64e-4070-7ff3-8462-31453df8e238`:

- plain: `exec-e8fc5674-71ef-412f-a0ba-76961b1e5252.png`;
- spots: `exec-e352106b-f1e0-4315-beeb-32c78ef45d54.png`;
- stripes: `exec-1e607f47-99f3-4e3d-9f9f-f6f30f10a68a.png`.

Runtime получает `*-body.png`: детерминированный export нижнего слоя с
кривой скрытого перекрытия под принятой головой. Генерированная голова
не используется. Исходники сохранены без изменений; параметры экспорта —
`scripts/export-puppet-groups.py`, hash lineage — `asset-manifest.json`.
Экспорт сохраняет принятие только при совпадении source/export hashes с
owner-acceptance.json; изменённая графика снова получает pending status.

Происхождение: собственный персонаж проекта и новые AI-generated варианты
по его принятому reference; сторонние персонажи/стоковые изображения не
использовались. Отдельная новая лицензия не заявляется; явная owner art acceptance
не подменяет проверку исполнения на устройстве.
